## Anti-Patterns Verdict

**LLM assessment**: Does not look AI-generated — looks like a developer prototype. Worse: it doesn't match the brand promise. "Occult. Theatrical. Dangerous." delivers "Functional. Dark. Done." The gold-on-dark has a hint of Balatro's energy but it's one accent in a sea of undifferentiated dark rectangles. No typography personality, no dramatic layout, no occult tension.

**Deterministic scan**: Detector returned empty array for both index.html and src/scenes/. Exit code 0. Expected — all UI is Phaser canvas; DOM/CSS pattern rules have nothing to scan. No false positives.

## Overall Impression

The game mechanics are genuinely interesting. The UI is holding them hostage. The single biggest opportunity is contrast: critical text labels are so dark they're invisible, and the brand promise of "theatrical" would be served by exactly those labels having presence. Fixing contrast and adding one distinctive font would close 60% of the gap.

## What's Working

1. Die type color language (ATK red, BLK blue, STR orange, VUL purple, FRL teal) — consistent across every scene. Real roguelike literacy system.
2. Physics feedback replaces animation — the die flying, hitting the bumper, bouncing back IS the animation. Earns real tension without explicit FX.
3. Class card structure — title, flavor, die loadout pills, starting relic, prompt in 108px card. Dense and mostly readable.

## Priority Issues

**[P0] Invisible text — contrast is broken**
Colors like #2a2a3a, #1e3a48, #2a3848, #2a3a4a on near-black backgrounds (0x111122, 0x0a0a18) are ~1.4:1 contrast ratio. WCAG requires 4.5:1 body / 3:1 large. Affected: "tap to play →" on all class cards, tutorial link, back arrow, "2 players · same device", all secondary labels.
Fix: Bring minimum secondary text to #7a9ab0. Anything carrying intent (tap to play, tutorial, back) must hit 4.5:1.
Command: /impeccable clarify

**[P1] No custom font — system default kills the brand**
Every scene uses system default font. An underground gambling hall run by The Devil can't look like a browser dev tool. Balatro, Slay the Spire both have distinctive typefaces. Typography is the cheapest lever here.
Fix: One Google Font for display text — Cinzel, Rye, Pirata One, or MedievalSharp. System sans stays for small body copy.
Command: /impeccable typeset

**[P1] Intent vocabulary never decoded — HUSTLE/LOADED/RATTLE are opaque**
INTENT map renames: strength→LOADED, vulnerable→HUSTLE, frail→RATTLE. Never explained in UI. Players face "HUSTLE" with zero context for what happens next.
Fix: Show mechanical effect under intent name: "HUSTLE (your dice –2)" or tap-intent popup with one-line decode.
Command: /impeccable clarify

**[P2] No escape from BattleScene**
No pause, exit, or state save. Mobile interruptions kill runs. No confirmation before losing progress.
Fix: Small pause/quit button in BattleScene header. Even intentional "quit run" beats silent state loss.
Command: /impeccable harden

**[P2] Intent chips in enemy selection are unlabeled color squares**
16×16 colored squares on enemy cards. No label. Players must already know color→meaning mapping to read them.
Fix: Pill with dot + "ATK"/"BLK"/"STR" at 8–9px. The 108×220 card has room.
Command: /impeccable clarify
